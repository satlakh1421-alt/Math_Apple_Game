# 🍎 Math Apple Game

An interactive, educational math game designed to make learning and practicing mathematics fun and engaging! 

---

## 🚀 Features

- **Interactive Gameplay:** Solve math problems dynamically while engaging with game elements.
- **Progressive Difficulty:** Challenges adapt or scale to test various mathematical skill levels.
- **Clean & Lightweight:** Built with simplicity and performance in mind.

---

## 🎮 How to Play

1. Start the game.
2. Read the math problem presented on the screen.
3. Select or input the correct answer (e.g., clicking on the correct apple/target).
4. Score points for correct answers and beat your high score!
